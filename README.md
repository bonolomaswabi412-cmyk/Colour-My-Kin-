# Colour My Kin

Android V1 project.

Features in the current prototype:
- My Photos
- Colouring Library
- Colouring Studio
- My Artwork
- Challenges
- My Profile / demo account

Build:
1. Push this folder to GitHub.
2. Open Actions.
3. Run "Build Colour My Kin APK".
4. Download the generated APK artifact.

This is a development APK. A production release needs secure authentication/backend storage, privacy policy, signing, and Play Store configuration.
